#Task Manager REST API

A simple REST API built using Flask to manage tasks.

Features
- Add new task
- View all tasks
- Update task status
- Delete tasks

Tech Stack
- Python
- Flask

API Endpoints

GET /tasks  
POST /tasks  
PUT /tasks/<id>  
DELETE /tasks/<id>

- How to Run

1. Install dependencies:
pip install flask

2. Run the app:
python app.py

3. Open:
http://127.0.0.1:5000/tasks
